# AirTouch — Беспроводной тачпад для ПК

Превращение смартфона (iPhone или Android) в отзывчивый тачпад и пульт управления компьютером через браузер. Без установки сторонних приложений и драйверов.

---

## Особенности подключения: ПК по кабелю, телефон по Wi-Fi

Сервер автоматически определяет физический сетевой адаптер компьютера (`Ethernet` / локальная сеть `192.168.x.x`), подключенный к домашнему роутеру, и игнорирует виртуальные туннели (VPN, TUN, TAP, WSL). 

Поскольку роутер объединяет проводную сеть и домашний Wi-Fi в единое адресное пространство, смартфон моментально находит компьютер.

---

## Быстрый старт

### 1. Полноценная версия (AirTouch Pro)
```bash
python touchpad_pro.py
```
* В консоли выводится QR-код и выбранный сетевой интерфейс.
* На экране монитора автоматически открывается минималистичная страница сопряжения в теплых спокойных тонах.
* Сканируйте QR-код камерой смартфона — управление курсором активируется сразу после перехода по ссылке.

### 2. Минималистичный скрипт (в ~20 строк)
```bash
python mini_touchpad.py
```
Решение на стандартной библиотеке Python (`http.server` + Win32 `ctypes`): ловит `touchmove` пальца по экрану через `fetch` и двигает системный курсор.

## Возможности AirTouch Pro

1. **Жесты управления:**
   - 1 палец — плавное перемещение курсора с динамическим ускорением.
   - Одиночный тап — левый клик (ЛКМ).
   - Тап двумя пальцами — правый клик (ПКМ).
   - Свайп двумя пальцами — прокрутка колесом мыши (Scroll).
   - Зажатие пальца (>360 мс) — режим Drag & Drop (выделение текста, перетаскивание окон).
   - Полоса прокрутки справа — быстрое колесико для пролистывания страниц одной рукой.
2. **Ввод текста:** трансляция текста и голосовой диктовки с клавиатуры смартфона прямо в активное окно ПК через Windows `SendInput` (поддержка русского языка и любых символов).
3. **Горячие клавиши:** Enter, Backspace, Esc, Space, Win, Tab, Ctrl+Z, Alt+Tab, регулировка громкости.
4. **Визуальное оформление:** минималистичный дизайн в сдержанных теплых тонах, чистая типографика без лишних графических элементов и смайликов.
5. **Предотвращение сна:** экран телефона не гаснет во время использования (Wake Lock API).

## Архитектура

* **Серверная часть:** Python 3 (чистый RFC 6455 WebSocket и встроенный `http.server`).
* **Управление курсором и вводом:** Windows `user32.dll` через `ctypes` (`mouse_event` и `SendInput`).
* **Клиент:** чистый HTML5/CSS/JS (Touch Events API, `touch-action: none`).
* **Задержка:** менее 1 миллисекунды по локальной сети.
